My Flow - personal workout tracker (PWA)
Files: index.html, app.js, styles.css, manifest.webmanifest, sw.js, apple-touch-icon.png, icons/
Host the whole folder on any HTTPS static host (GitHub Pages, Netlify Drop, Cloudflare Pages...).
iPhone: open the https link in Safari > Share > Add to Home Screen. It then runs full-screen and offline.
Data lives in the phone's localStorage. Use Settings > Export backup regularly.
